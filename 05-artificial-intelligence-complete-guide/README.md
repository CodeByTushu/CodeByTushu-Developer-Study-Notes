## 🚀 How to Run the Code

### Python Setup:
```bash
cd src/python
pip install -r requirements.txt
python 02_embeddings_similarity.py
```

### Run Chat Completion (Requires `OPENAI_API_KEY`):
```bash
export OPENAI_API_KEY="your-key"
python 01_chat_completion.py
```
