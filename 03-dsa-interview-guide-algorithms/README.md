## 💡 Top Interview Patterns Covered

| Pattern | Time Complexity | Auxiliary Space | Best Used For |
| :--- | :--- | :--- | :--- |
| **BFS Traversal** | $O(V + E)$ | $O(V)$ | Shortest path in unweighted graphs, level-order |
| **Dijkstra’s Algorithm** | $O((V + E) \log V)$ | $O(V)$ | Non-negative edge weights shortest path |
| **0/1 Knapsack** | $O(N \cdot W)$ | $O(W)$ | Resource allocation with binary choices |
| **Coin Change DP** | $O(A \cdot N)$ | $O(A)$ | Minimum subproblem combinations |
